## Open Source Projects

### [Capture](https://github.com/jakkapan1789/capture)

A lightweight desktop screen-capture tool with fully re-editable annotations.
Built with Tauri 2 (Rust + system WebView) and Konva, keeping the bundle to a few
megabytes while offering annotation features comparable to commercial tools.

[![Tauri](https://img.shields.io/badge/Tauri%202-24C8DB?logo=tauri&logoColor=white&style=flat)](https://tauri.app)
[![Rust](https://img.shields.io/badge/Rust-000000?logo=rust&logoColor=white&style=flat)](https://www.rust-lang.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white&style=flat)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/github/license/jakkapan1789/capture?style=flat)](https://github.com/jakkapan1789/capture/blob/main/LICENSE)
[![Stars](https://img.shields.io/github/stars/jakkapan1789/capture?style=flat&logo=github)](https://github.com/jakkapan1789/capture)

- Region and full-screen capture with a rebindable global hotkey
- Annotation toolset: arrows, boxes, highlighter, wrapped text, auto-numbering step badges, blur and pixelate
- Non-destructive architecture — the original PNG is never modified; annotations are stored as JSON and flattened only on export
- Auto-saving history that allows past captures to be reopened and edited
- On-device OCR using native OS APIs, with no data leaving the machine
